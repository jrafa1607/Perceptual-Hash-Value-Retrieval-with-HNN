# Databases Information 

All the information about the Databases would be used in the Experiments.

- <b> Lenna Database </b> (01 Original Image and 20 Alternative): Total - 21 Images
- <b> Washington Database </b> (01 Original Image and 06 Alternative): 7 Images

Both LennaDatabase and WashingtonDatabase are selected from the publication: Images from Digital Image Processing, 3rd ed, by Gonzalez and Woods. Available at Link: https://imageprocessingplace.com/root_files_V3/image_databases.htm

- <b> PalaceDatabase </b> (01 Original Image and 30 Alternative): 31 Images
- <b> MountainDatabase </b> (01 Original Image and 30 Alternative): 31 Images

Both PalaceDatabase and MountainDatabase were selected from the Dataset: SUID: Synthetic Underwater Image Dataset. Available at Link: https://ieee-dataport.org/open-access/suid-synthetic-underwater-image-dataset

- <b> ParkDatabase </b> (01 Original Image and 10 Alternative): 11 Images

The ParkDatabase was selected from the Dataset: CoMoFoD - Image Database for Copy-Move Forgery Detection. Available at Link: https://www.vcl.fer.hr/comofod/download.html
